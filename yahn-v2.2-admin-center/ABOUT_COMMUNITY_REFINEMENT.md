# Sustainable Community Refinement

Perubahan pada tab **Sustainable Community** di `/tentang`:

- Diagram komunitas dibuat ulang sebagai elemen web/CSS, bukan gambar statis.
- Ring oranye, tiga node komunitas, dan titik konektor mengikuti referensi visual terbaru.
- Logo YAHN digunakan sebagai watermark halus dan mark di pusat diagram.
- Pusat diagram menampilkan **Nilai AHN**.
- Tiga peran dibuat lebih informatif: Alumni, Penerima Beasiswa, dan Sahabat YAHN.
- Layout responsif untuk desktop, tablet, dan mobile.
