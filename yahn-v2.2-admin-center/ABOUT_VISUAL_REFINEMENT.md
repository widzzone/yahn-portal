# About Foundation Visual Refinement

Perbaikan pada halaman `/tentang`:
- logo YAHN di hero tidak lagi terpotong;
- logo menggunakan frame proporsional dengan `max-height` agar seluruh gambar portrait tampil utuh;
- hero dibuat lebih ringkas dan seimbang;
- area Profil Yayasan dibuat lebih premium dengan tab bernomor;
- panel Tujuan Yayasan menggunakan visual teal kontras;
- lima kegiatan dibuat lebih compact dan mudah dipindai;
- tab Nilai, Sustainable Community, dan Struktur Organisasi ikut dipadatkan;
- responsif untuk desktop, tablet, dan mobile.

Tidak ada perubahan Apps Script, database, API secret, atau environment variable.
