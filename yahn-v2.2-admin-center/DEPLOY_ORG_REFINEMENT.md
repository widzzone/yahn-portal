# YAHN — Struktur Organisasi Visual Refinement

Patch ini hanya memperbarui tampilan tab **Struktur Organisasi** pada halaman `/tentang`.

## File yang ditimpa
- `components/AboutCompactTabs.tsx`
- `app/globals.css`

## Perubahan
- Card Pembina, Pengurus, dan Pengawas dibuat lebih modern dan seimbang.
- Pengurus menjadi focal point dengan executive grid 2x2.
- Nama anggota menggunakan chip agar tidak berdesakan.
- Ketua tiap kelompok dibuat sebagai highlight tersendiri.
- Tetap responsif untuk desktop, tablet, dan mobile.

Tidak ada perubahan pada Apps Script, database, environment variable, QRIS, atau API.
