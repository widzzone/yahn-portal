# Deploy V2.9

V2.9 adalah patch frontend di atas V2.8. Backend Apps Script V2.8 tetap dipakai.

1. Upload isi patch ke root project GitHub yang sedang dibaca Vercel.
2. Timpa file lama jika diminta.
3. Commit changes.
4. Vercel akan melakukan deployment otomatis.

Tidak perlu mengubah:
- Root Directory Vercel
- Environment Variable
- Apps Script
- Script Properties
- Spreadsheet
