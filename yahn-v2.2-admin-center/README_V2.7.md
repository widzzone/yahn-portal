# YAHN V2.7 Experience Polish

Fokus V2.7:

1. Portal Sahabat YAHN lebih compact dan lebih hangat.
2. Wording publik donor/donatur diperhalus menjadi Sahabat YAHN, dukungan, dan berbagi.
3. Admin Center tetap menyatu untuk Beasiswa + Dukungan, dengan copy yang lebih rapi.
4. Header mobile sekarang memiliki hamburger menu.
5. Landing page dibuat lebih ringkas dan premium tanpa menambah scroll.
6. Dashboard Sahabat menggunakan tab Ringkasan / Riwayat / Kakak Asuh / Dampak.

Tidak ada perubahan Apps Script atau database wajib pada V2.7.

## Cara install
Upload isi patch ke root project GitHub yang saat ini dibaca Vercel. Timpa file dengan nama sama, commit, lalu tunggu deployment Vercel.
